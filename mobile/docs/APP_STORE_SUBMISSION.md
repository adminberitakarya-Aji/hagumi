## Review Guidelines

### What to Highlight

1. **Emotional Connection**: Emphasize the bond between player and pet
2. **Visual Appeal**: Showcase kawaii aesthetics and beautiful graphics
3. **Fair Monetization**: Highlight ethical gacha and cosmetics-only approach
4. **Social Features**: Mention friend system and community
5. **Cross-Platform**: Note availability on web and desktop

### What to Avoid

1. **Don't** mention competitor names
2. **Don't** make false claims about features
3. **Don't** use misleading screenshots
4. **Don't** promise features not yet implemented
5. **Don't** use excessive emojis in official descriptions
