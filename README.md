# 🌸 Hagumi (育み) — Virtual Pet Game

Raise and bond with your magical virtual pet in a Japanese-inspired world.

## 🚀 Quick Start

1. **Install Dependencies**
   ```bash
   npm install
   ```

2. **Setup Supabase**
   - Create a project on [Supabase](https://supabase.com).
   - Run the SQL in `supabase/migrations/001_initial_schema.sql`.
   - Copy your credentials to `.env`.

3. **Run Development Server**
   ```bash
   npm run dev
   ```

## 🛠 Tech Stack
- **Frontend**: React + Vite + TypeScript
- **Styling**: Tailwind CSS + Framer Motion
- **Backend**: Supabase (Auth + DB)
- **AI**: Anthropic Claude API
- **PWA**: vite-plugin-pwa

## 🎮 Features
- **Dynamic Background**: Changes based on real-world time.
- **AI Chat**: Talk to your pet using Claude AI.
- **Breeding**: Create new generations of pets.
- **Market**: Trade items with other players.
- **PWA**: Installable on mobile devices.
